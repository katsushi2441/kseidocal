# Kurage 経営者の制度カレンダー（kseidocal）

会社に降ってくる制度の変更（取適法・最低賃金・社会保険の適用拡大・カスタマーハラスメント対策・ストレスチェック・雇用保険・子ども子育て支援金・インボイス）を施行日の順に並べ、従業員数などから自社に関係するものと時期を出す1ファイルの PHP です。項目ごとに、国会での直近の議論（国立国会図書館 国会会議録検索システム API・1日キャッシュ）、会社がやること、省庁の公式の出典を載せます。iCalendar（`/cal.ics`）でカレンダーアプリに入れられます。

公開: https://kurage.exbridge.jp/kseidocal.php/

置き方: `php/kseidocal.php` を PHP 8.1 以上（curl 拡張）のサーバーに置くだけ。`kseidocal_data/cache` に書き込めること。項目は `ITEMS` 定数で、日付は必ず省庁の公式ページで確かめてから足す。
